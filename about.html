About

這個網站是怎麼長出來的

每一頁概念，都是 AI 讀完工作手冊 AGENTS.md 後，從一份私人 LLM Wiki 改寫出來的。手冊規定網站的目的、風格、頁面格式、檔案位置，以及哪些內容可以公開。

三層分工

私人 LLM Wiki課堂講義、論文摘要、專案紀錄、人物頁。只存在本機，不上傳。
→
AGENTS.md 規則決定什麼能公開、要怎麼改寫、放在哪裡、長什麼樣子。
→
公開網站content/ 放改寫後的概念頁，data/pages.json 是索引，網頁外殼固定不動。

所以新增內容不用碰 HTML：網頁外殼只寫一次，之後每個新頁面都只是「一個 Markdown 檔＋索引裡的一筆資料」。

每一頁都長一樣

每個概念頁固定五個區塊，順序不能改：

  1. 一句話：沒學過的人也能抓到重點
  2. 定義：正式定義與公式，每個符號都解釋
  3. 直覺理解：用例子講「為什麼會這樣」
  4. 常見誤解與限制：模型什麼時候會失效
  5. 延伸閱讀：公開文獻

固定格式讓讀者每一頁都知道去哪裡找什麼，也讓 AI 不用每次重新決定版面。

新增一頁只要一句話

要把私人 wiki 裡的某個概念上架，只要對 AI 說：

請先讀 AGENTS.md，然後把 wiki 的 idiosyncratic-volatility 上架成概念頁。

AI 會依手冊第 7.1 節的流程做事：

  1. 查 data/pages.json 確認還沒有這一頁
  2. 讀私人 wiki 的原始概念頁與相關來源，理解脈絡
  3. 選分類、程度、關鍵字與相關概念
  4. 照模板寫出五個區塊，同時依隱私規則拿掉不能公開的內容
  5. 在索引加一筆，並把新頁面雙向連到相關概念
  6. 執行 python tools/check_site.py，全部通過才算完成

隱私守門

私人筆記裡混著不該公開的東西：同學和講者的名字、社團內部資訊、升學規劃、專案的實際績效數字，以及有版權的論文全文。手冊第 6 節把這些列成「永遠不能出現在網站上」的清單，檢查腳本也會自動掃描關鍵字，並比對私人 wiki 人物頁裡的人名。

技術

  • 純 HTML／CSS／JavaScript，沒有建置步驟，放上 GitHub Pages 就能看
  • Markdown 用 marked 轉換、數學式用 KaTeX 排版（兩者都已放在 repo 內，不依賴外部 CDN）
  • tools/check_site.py 檢查索引一致性、頁面結構、雙向連結與隱私關鍵字
